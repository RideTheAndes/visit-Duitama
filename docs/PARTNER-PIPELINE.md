# PARTNER-PIPELINE — mapa de agentes potenciales de Visit Duitama

Primer mapeo de restaurantes, hospedajes, operadores, servicios, escuelas de idiomas e instituciones que podrían integrarse a la plataforma (red Verified Partner o alianzas). Investigación de escritorio: **agosto 2026**, vía búsqueda web sistemática por industria.

**Regla de lectura:** nada de lo listado aquí está verificado en persona. Este documento es la *lista de visitas*, no el registro. Coherente con la regla de la marca (§10 del BRIEF): un agente entra al sitio público solo después de la verificación de 4 chequeos (visita, consumo, horarios ×2, inglés).

**Prioridad sugerida** (fit con la marca — inglés, nombre propio, historia, calidad):
- **A** — candidato natural a Verified Partner o alianza estructural; visitar primero.
- **B** — potencial real; segunda ola.
- **C** — completar cobertura / dato de contexto.

## Fuentes estructuradas pendientes de descarga

El entorno donde se hizo esta investigación tiene bloqueado el egress a datos.gov.co y situr.boyaca.gov.co. **Estos dos datasets son la vía más completa y gratuita** — descargarlos desde cualquier navegador o terminal sin restricciones:

1. **Base de Prestadores de Servicios Turísticos "SITUR" — Boyacá** (RNT por categoría; corte publicado 2021, revisar actualización):
   ```
   curl "https://www.datos.gov.co/resource/j8bh-xk3n.json?\$limit=5000" -o situr-boyaca.json
   ```
2. **Vista Registro Nacional de Turismo — Boyacá**:
   ```
   curl "https://www.datos.gov.co/resource/sy6b-wqde.json?\$limit=5000" -o rnt-boyaca.json
   ```
   Filtrar por municipio en la propia URL (ajustar el nombre de columna al esquema real):
   ```
   ...json?$where=upper(municipio) like '%25DUITAMA%25'
   ```
3. **Cámara de Comercio de Duitama** — pedir cotización de base de datos por actividad económica (códigos CIIU: 5611 restaurantes, 5511 hoteles, 7911/7912 agencias y operadores, 8553/8559 enseñanza de idiomas, 4921/4922 transporte). Es el único censo completo con matrículas activas y renovadas.

## Método recomendado (evaluación)

1. **Descargar RNT/SITUR filtrado por Duitama** → columna vertebral del pipeline formal (quién tiene registro turístico activo). Gratis, estructurado, oficial.
2. **Comprar/pedir la base CIIU a la Cámara de Comercio** → cubre lo que el RNT no ve (restaurantes y cafés no necesitan RNT; escuelas de idiomas tampoco).
3. **Google Places API** (requiere API key propia) → completar teléfono, horario, rating y web de cada candidato de este documento en un solo script.
4. **Campo** → la verificación de 4 chequeos de la marca. Ninguna base reemplaza esto; las bases solo ordenan la fila de visitas.
5. Registrar cada verificación aquí y promover los aprobados a `COPY-EN.md` / al sitio.
